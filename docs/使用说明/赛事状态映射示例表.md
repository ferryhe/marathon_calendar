# 赛事状态映射示例表

基于当前实现（`shared/status.ts`）的展示规则，状态最终会按以下优先级计算：
1. 显式状态归一化（包括中文/英文历史别名）；
2. 如果显示状态是 `upcoming` 且有比赛日期，且距离比赛不超过 14 天，则按日期重算；
3. 无法确定时，返回 `tba`；
4. 否则按日期字段 `computeEditionStatus` 计算。

## 一、字段定义

| 字段 | 说明 |
|---|---|
| `raceDate` | 比赛日期 |
| `registrationOpenDate` | 报名开始日期 |
| `registrationCloseDate` | 报名截止日期 |
| `status` | 源状态（含来源历史文案） |

## 二、示例状态映射

| 场景 | 输入 | 计算结果 |
|---|---|---|
| 只有比赛日期（有 `raceDate`，无 `registrationOpenDate` / `registrationCloseDate`） | `raceDate=未来`，其他报名字段缺失 | `imminent` |
| 只有比赛日期且就是今天 | `raceDate=today` | `racing` |
| 比赛已结束 | `raceDate` 在今天之前 | `ended` |
| 报名正在进行（有开始且未截止） | `registrationOpenDate <= today <= registrationCloseDate` | `open` |
| 报名还没开始（有报名开始日） | `today < registrationOpenDate` | `upcoming` |
| 报名截止，但离比赛 14 天内 | `today > registrationCloseDate` 且 `raceDate - today <= 14` | `imminent` |
| 报名截止，但离比赛超 14 天 | `today > registrationCloseDate` 且 `raceDate - today > 14` | `closed` |
| 显式状态是即将开始类 | `status=imminent/startingsoon/abouttostart/...` | `imminent` |
| 显式状态是未开始类 | `status=upcoming/notopen/notyetopen/comingsoon/报名未开始/未开放` | `upcoming` |
| 显式状态是即将开赛且比赛日期在 14 天内（特殊规则） | `status=upcoming` + `raceDate` 在 14 天内 | 重算后仍按日期返回（通常为 `imminent`） |
| 无有效状态且有时间信息 | `status` 缺失，且任一日期存在 | 走日期计算（可能是 `imminent/open/closed/...`） |
| 无有效状态且无任何时间字段 | `status` 缺失，日期字段也都缺失 | `tba` |

## 三、UI 上可见映射

| 展示态 | 文案键 |
|---|---|
| `upcoming` | `status.upcoming`（中文：报名未开始） |
| `imminent` | `status.imminent`（中文：即将开始） |
| `open` | `status.open`（中文：报名中） |
| `closed` | `status.closed`（中文：报名已截止） |
| `racing` | `status.racing`（中文：比赛中） |
| `ended` | `status.ended`（中文：已完赛） |
| `cancelled` | `status.cancelled`（中文：已取消） |
| `tba` | `status.tba`（中文：待定） |
